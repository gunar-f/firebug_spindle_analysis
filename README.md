# Quantitative analysis of spindle and chromosome dynamics in *Pyrrhocoris apterus*

This repository contains the analysis pipeline used in:

> Lindner A\*, Fabig G\*, Okafornta CW, Tulok S, Nobst A, Smýkal V, Doležel D,
> Paliulis L, Müller-Reichert T (\*joint first authors).
> "Meiosis I and II share chromosome dynamics distinct from mitosis in the
> firebug *Pyrrhocoris apterus*."

The pipeline reproduces all quantitative results of the manuscript: distance
traces (P-P, C-C, P-C), segregation speeds, anaphase A/B contributions, the
cell-size scaling analysis, and the main and supplementary figures and tables
(Figs. 1C, 1F, 3C, 4A–F, S1–S4; Tables 1, 2, S1, S2).

## How it works

Each input CSV is one cell: column 1 = time in seconds (relative to anaphase
onset), column 2 = distance in µm. For every track, a four-parameter logistic
is fitted **only** to locate the end of directed movement (95 % of its total
change); the reported speed is the slope of a linear fit over that movement
window, applied identically to chromosome-to-chromosome (C-C), pole-to-pole
(P-P) and derived pole-to-chromosome (P-C = (P-P − C-C)/2) distances.
Anaphase A/B contributions are computed per cell from paired changes in
distance (B = 100 × ΔP-P/ΔC-C; A = 100 − B). Cell-area matching for the
scaling analysis pairs each area record to a fitted C-C track by division and
animal ID, never reusing a track (audited in Table S2).

## Supplementary tables produced by this pipeline

- **Table S1** (`TableS1_percell.csv` / `.xlsx`): per-cell spindle and
  chromosome dynamics for all analyzed tracks (137 tracks). Contains the
  fitted initial and final distances, the windowed-linear speed, the linear
  R², and the movement-window start/end times for every C-C, P-P and P-C
  track.
- **Table S2** (`TableS2_scaling_match.csv` / `.xlsx`): audit of the matching
  of cell-area records to fitted C-C tracks used in the scaling analysis
  (Fig. 4D/E). Each area record is paired by division and AL number,
  disambiguating multiple sub-cells by closest final spindle length, and no
  track is reused (47 matched cells; two meiosis II cells lack a measured
  final spindle length in the area file and are flagged).

**Note:** Table S3 (summary metadata of all data sets used in this study) is
*not* generated by this pipeline; it is prepared separately and supplied with
the manuscript as a supplementary file.

## Requirements

- Python 3.12
- numpy, pandas, scipy, matplotlib, openpyxl, xlsxwriter, jupyter
  (see `requirements.txt`)

## How to run

1. Clone or download this repository.
2. Install the dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Start Jupyter and open the notebook:
   ```bash
   jupyter notebook Analysis_Firebug_spindles.ipynb
   ```
4. Run all cells (Kernel → Restart & Run All).

All figures (PDF, 300 dpi, editable text) and tables (CSV + XLSX) are written
to `pipeline_output/figures/`. The notebook is self-contained: no paths need
to be edited, provided the folder structure above is preserved.

## Data provenance

Tracking data were extracted from phase-contrast time-lapse recordings of
spermatocytes/spermatogonia as described in the Methods section of the
manuscript (manual pole tracking in FIJI; kymograph generation with
"Kymograph generation for 3D image", Okafornta 2025, Zenodo). Pixel size:
0.0454 µm/pixel. In total: 20 meiosis I cells, 20 meiosis II cells, 7 mitotic
cells (137 fitted tracks).
